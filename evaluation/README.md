# evaluation/ — the Diagnowise Clinical Evaluation Framework

**Status: future. Not part of the current build sequence (backend → AI
orchestration → API).**

Tests differential quality, dangerous-diagnosis recall, red-flag detection,
contradiction detection, hallucination, calibration, bias across
age/sex/geography/setting, and robustness to incomplete or contradictory
input (strategy doc §15). Long-term home of the public Diagnowise Benchmark
(strategy doc §16) — synthetic and appropriately governed test cases only,
never real patient data.
